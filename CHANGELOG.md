## [1.0.0] - 2026-08-14

### Added
- Institutional quantitative platform core architecture.
- Server-side OAuth 2.0 PKCE authentication flow for Deriv broker integration.
- Database connection pool, migrations, and automated seed data runner for PostgreSQL.
- SMC and ICT strategy framework and algorithmic signal engine.
- Comprehensive technical documentation suite and open-source repository structure.
