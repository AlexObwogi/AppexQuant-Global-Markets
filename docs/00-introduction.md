# 00. Introduction

Welcome to **AppExQuant Markets Global**, an institutional quantitative technology platform designed for market intelligence, quantitative strategy research, risk management, execution routing, and automated trading infrastructure.

## Purpose of This Manual

This technical documentation serves as the permanent engineering memory of AppExQuant. It defines the exact architecture, verified implementation status, database schemas, authentication flows, and extensibility contracts required by engineers, quants, and contributors.

## Core Philosophy

1. **Reality First**: Code documentation reflects exact current implementation, clearly separating implemented features from proposed architecture.
2. **Modular Architecture**: Market data, quantitative features, strategies, signals, risk controls, and broker execution are strictly decoupled.
3. **Institutional Security**: OAuth 2.0 PKCE authentication, secure HTTP-only cookies, and centralized risk firewalls protect all operations.
