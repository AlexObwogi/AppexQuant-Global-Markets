# Security Policy

AppExQuant Markets Global takes security very seriously. As an institutional quantitative platform handling trading execution and financial credentials, we maintain rigorous security standards.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

---

## Reporting a Vulnerability

If you discover a security vulnerability within AppExQuant, please report it responsibly. **Do not disclose security vulnerabilities publicly until they have been addressed by the maintainers.**

- **Email**: security@appexquant.internal
- **Encrypted Reporting**: Use our PGP key available upon request.

Please include:
- Description of the vulnerability
- Steps to reproduce or proof-of-concept
- Potential impact (e.g., session hijacking, unauthorized execution, data exposure)

We will acknowledge receipt within 48 hours and provide regular status updates during remediation.
